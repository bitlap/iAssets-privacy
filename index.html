iAssets 隐私政策

更新日期：2025年7月12日

iAssets（股票持仓）是一款个人股票持仓管理工具。我们重视您的隐私，本隐私政策说明了我们如何处理您的数据。

数据存储

您的所有投资数据（包括股票持仓、操作记录、派息记录等）均存储在您的设备本地以及您自有的 iCloud 账户中。我们不会在服务器端存储或传输您的任何个人投资数据。

第三方服务

App 使用以下第三方公开 API 获取行情与汇率数据，这些请求仅用于查询股票价格和汇率信息，不涉及您的个人数据：

• 东方财富 API — 用于股票搜索与代码查询
• 腾讯股票行情 API — 用于获取实时股价与涨跌幅
• ExchangeRate-API — 用于获取实时汇率数据

数据收集

本 App 不收集、不存储、不传输任何个人身份信息、设备信息或使用行为数据。App 不包含广告 SDK、分析 SDK 或任何第三方数据收集组件。

Apple 数据

App 可能使用 Apple 提供的标准功能（如 iCloud 同步）来备份和恢复您的数据，相关数据处理遵循 Apple 的隐私政策。

未成年人

本 App 不面向 13 岁以下儿童，不会故意收集儿童的个人信息。

政策更新

我们可能会不时更新本隐私政策。如有重大变更，我们将在 App 内或 App Store 页面进行通知。
